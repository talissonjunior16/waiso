The first account created on an empty database becomes the Admin.

Licensing: a new instance runs fully for 14 days. After that it needs a license —
apply the license token and check-in key in Settings → License. A licensed
instance checks in with https://api.waiso.com.br every hour, so it needs outbound
HTTPS; after 2 days without a successful check-in it enters grace mode:
everything stays readable, but nothing new runs until it checks in again.
Enterprise can be licensed offline instead.
